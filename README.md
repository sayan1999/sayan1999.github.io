# AI System Designs for Production

Personal site for [@aiwithsayan](https://linkedin.com/in/sdey) — engineering playbooks for modern AI stacks.

**Stack:** React + Vite · Tailwind CSS · deployed via `gh-pages`

## Dev

```bash
npm install
npm run dev       # localhost:5173
npm run deploy    # build + push to gh-pages branch
```

## Adding a post

1. Create `public/content-lab/<slug>/article.md` with frontmatter + caption
2. Add `public/content-lab/<slug>/artifact.pdf`

`manifest.json` is auto-generated by the Vite plugin — no other changes needed.
